
This is the readme file for the R scripts of the paper “Minimax and Adaptive Transfer Learning for Sparse Canonical Correlation Analysis” by Bo Fu, and Dandan Jiang. 

Explanation of files:

The "simulation1_trans_scca-cor_CV.R" is the main R code for simulations of prediction error in Section 5.1.
The "simulation2_normalization_loss_cor_CV_fullsample.R" is the main R code for simulations of prediction error without sample splitting in Section C.2.
The "simulation1_normalization_loss_cor_CV.R" is the main R code for simulations of normalization error in Section C.1.
The "simulation2_normalization_loss_cor_CV_fullsample.R" is the main R code for simulations of normalization error without sample splitting in Section C.2.
The "real data_preparation.R" is the R code for pre-processing the real data in Section 5.2.
The "real data_trans_scca.R" is the main R code for reproducing the real data in Section 5.2.
